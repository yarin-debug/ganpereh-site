## 1. איך זה עובד

```
שינוי ← PR ← GitHub מריץ את השער אוטומטית ← דוח כתגובה ב-PR ← ירוק: אפשר למזג · אדום: חסום
```

1. **שרת מקומי** מרים את האתר בדיוק כמו שהוא (האתר סטטי, אין שלב בנייה).
2. **Playwright** (דפדפן שנשלט מקוד) פותח את העמודים בחמישה גדלי מסך ומריץ את החוקים.
3. **דוח** נכתב כתגובה ב-PR: ✅/❌ לכל חוק, ולכל כישלון העמוד, הרוחב וצילום.
4. **אותה פקודה רצה גם מקומית** (`npm run check`), כך שקלוד מריץ אותה בסשן לפני שהוא פותח PR, ולא מגלה את הבעיה רק ב-GitHub.

**למה האתר ראשון:** סטטי, בלי התחברות ובלי מסד נתונים. זה המקום הזול ביותר להוכיח שהשיטה עובדת לפני שעוברים לדשבורד.

## 4. שכבת ה-AI — שלב מאוחר, ממליצה בלבד

רק אחרי שהשער הדטרמיניסטי יציב. סוקר AI עובר על השינוי ועל הצילומים מול ספר חוקים קצר, שלא ניתן לבדוק במדידה:

- טון המותג: בלי סופרלטיבים, בלי "בלי קבלני משנה", בלי קלישאות גינון
- "האם זה מתחרה בתמונה?" (עקרון-העל של שדרוג העיצוב)
- עקביות עם עמודים אחים: אותה תבנית, אותו מבנה

**היא לא חוסמת לעולם.** בהתחלה היא רצה בתוך סשן קלוד לפני פתיחת PR, על המנוי הקיים ובלי מפתח API בתשלום. היא עוברת ל-GitHub רק אם יתברר שהיא תופסת דברים שהשער לא תופס.
