# שער בדיקות — האתר

כל שינוי באתר עובר כאן לפני שהוא עולה לאוויר. כל חוק נולד מתקלה שכבר קרתה;
התוכנית המלאה והרקע: `docs/תוכנית-שער-בדיקות.md`.

## הרצה

```bash
npm install          # פעם אחת
npm run check        # הכול, כ-2 דקות
npm run check -- --fast        # בלי דפדפן — חוקי הטקסט בלבד, שניות
npm run check -- --only=1,9    # רק החוקים האלה
```

הדוח נכתב ל-`checks/out/report.md`. ב-GitHub הוא מתפרסם כתגובה ב-PR.
מקומית, אם הדפדפן של Playwright לא מותקן, השער משתמש ב-Chrome שבמחשב.

## כשחוק נכשל

1. **קודם לחשוד בשינוי, לא בחוק.** כל חוק כאן תפס פעם תקלה אמיתית.
2. אם ההכרעה העסקית באמת השתנתה (מספר חדש, מחיר שהותר) — מעדכנים את
   `config.mjs`, ובקומיט כותבים מי הכריע ומתי.
3. חוק שחסם בטעות פעמיים — מתקנים אותו או מורידים להתרעה. לא משאירים רעש.

## כללי ריצה

- **אפס לידים אמיתיים, בשתי שכבות.** (1) השרת המקומי מחליף בזמן ההגשה את
  כתובות הדשבורד ו-Formspree בדומיין `.invalid`, שלעולם אינו מגיע לשום שרת
  (`SANDBOX` ב-`lib/server.mjs`). (2) כל פנייה החוצה מיורטת בדפדפן: ל-`.invalid`
  — תשובת הצלחה מדומה, שחוק 5 בודק את תוכנה; לכל השאר (GA4, פיקסל) — תשובה
  ריקה. פנייה שבכל זאת מכוונת לכתובת אמיתית נחסמת ומדווחת כ-🚨 — סימן
  שנוספה נקודת שליחה שצריך להוסיף ל-`SANDBOX`.
- פרטי הבדיקה בטפסים: השם "בדיקה אוטומטית" והטלפון 050-0000000 (ה-placeholder).
- באנר העוגיות נסגר ב"בלי כלי פרסום" — הבחירה ששומרת על פרטיות.
- מחרוזות פרטיות נשמרות ב-`config.mjs` כטביעת אצבע (sha256) ולא כטקסט —
  GitHub Pages מפרסם גם את התיקייה הזו.
- חוק 11 מריץ את המחוללים בעותק זמני. המאגר עצמו לא נוגע.

## למה חוקים 8, 13–15 משווים מול main ולא מול קובץ שמור

GitHub מצייר פונטים מעט אחרת מהמק (אותה גלישה נמדדה 11px שם ו-18px כאן), ולכן
רשימת "יתומים קיימים" שנשמרה במחשב אחד תייצר התרעות שווא במחשב אחר. במקום זה
השער מושך את `origin/main` לתיקייה זמנית ומודד את שתי הגרסאות באותה ריצה —
ומדווח רק על מה שהשינוי הוסיף. שינוי שלא נוגע ב-HTML, CSS, JS, פונטים
או partials מדלג עליהם לגמרי. `SHAAR_ALL=1 npm run check` מודד את כל התבניות.

## צילומי לפני/אחרי

השער מצלם כל עמוד שהשינוי נוגע בו, ב-390 וב-1280, בשתי הגרסאות, ומשווה
פיקסלים. אם אין הבדל — אין תמונה ("בלי שום שינוי חזותי"). אם יש — תמונה אחת:
**לפני מימין, אחרי משמאל**, חתוכה לאזור שהשתנה, ופס אדום לצד השורות שזזו.
מקומית: `checks/out/screens/`. ב-PR: מוצגות בתגובה, מתוך הענף `shaar-tzilumim`
(ה-API של GitHub לא מאפשר לצרף תמונה לתגובה). מותר למחוק את הענף מדי פעם.

לפני הצילום האנימציות מוקפאות ותוכן "חשיפה בגלילה" מוצג — אחרת חצי עמוד
יוצא לבן. main מול עצמו: 0 הבדלים ב-18 צילומים.

## הוספת חוק

רק אחרי תקלה שחמקה לאוויר. קובץ ב-`rules/` שמייצא `{ id, title, severity, run }`,
כש-`run` מחזיר `{ checked, failures: [{ where, msg }] }`, ושורה ב-`run.mjs`.
ובראש הקובץ — ממה החוק נולד.
