# שער בדיקות — האתר

כל שינוי באתר עובר כאן לפני שהוא עולה לאוויר. כל חוק נולד מתקלה שכבר קרתה;
התוכנית המלאה והרקע: `docs/תוכנית-שער-בדיקות.md`.

## הרצה

```bash
npm install          # פעם אחת
npm run check        # הכול, כ-2 דקות
npm run check -- --fast        # בלי דפדפן — חוקי הטקסט בלבד, שניות
npm run check -- --only=1,9    # רק החוקים האלה
```

הדוח נכתב ל-`checks/out/report.md`. ב-GitHub הוא מתפרסם כתגובה ב-PR.
מקומית, אם הדפדפן של Playwright לא מותקן, השער משתמש ב-Chrome שבמחשב.

## כשחוק נכשל

1. **קודם לחשוד בשינוי, לא בחוק.** כל חוק כאן תפס פעם תקלה אמיתית.
2. אם ההכרעה העסקית באמת השתנתה (מספר חדש, מחיר שהותר) — מעדכנים את
   `config.mjs`, ובקומיט כותבים מי הכריע ומתי.
3. חוק שחסם בטעות פעמיים — מתקנים אותו או מורידים להתרעה. לא משאירים רעש.

## כללי ריצה

- כל פנייה מחוץ לשרת המקומי (GA4, פיקסל מטא, הדשבורד) מקבלת תשובה ריקה:
  בדיקה לא נרשמת כביקור ולא יוצרת ליד.
- מחרוזות פרטיות נשמרות ב-`config.mjs` כטביעת אצבע (sha256) ולא כטקסט —
  GitHub Pages מפרסם גם את התיקייה הזו.
- חוק 11 מריץ את המחוללים בעותק זמני. המאגר עצמו לא נוגע.

## הוספת חוק

רק אחרי תקלה שחמקה לאוויר. קובץ ב-`rules/` שמייצא `{ id, title, severity, run }`,
כש-`run` מחזיר `{ checked, failures: [{ where, msg }] }`, ושורה ב-`run.mjs`.
ובראש הקובץ — ממה החוק נולד.
