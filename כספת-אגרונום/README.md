# כספת האגרונום — מאגר ידע מקצועי של גן פרח

מאגר ידע פנימי שמצטבר עם הזמן. המטרה: **לענות פעם אחת ולתעד**, כדי שבעתיד לא נחזור על אותו מחקר (חיסכון בזמן ובטוקנים).

## איך משתמשים
- לפני מחקר על נושא מקצועי — בדקו קודם אם יש כאן ערך קיים.
- ערך חדש = קובץ `.md` נפרד בתיקייה הזו, עם תקציר מהיר (TL;DR) בראשו.
- מעדכנים ערך קיים כשמתגלה מידע חדש/מדויק יותר, ומעדכנים את תאריך העדכון בקובץ.

## הערה
זהו ידע מקצועי כללי בלבד — **אין כאן פרטי לקוחות או מידע עסקי רגיש**. מסמכים רגישים נשמרים מחוץ ל-repo (ראו `.gitignore`).
