# תמונות האתר — מקור האמת

התיקייה הזו היא **המקום היחיד** שבו נקבע אילו תמונות מופיעות באתר ואיפה.
אתה מסדר פה תיקיות וגורר קבצים; סקריפט אחד הופך את זה לאתר.

> התיקייה נשמרת מקומית בלבד (לא נדחפת ל-GitHub) — היא מחזיקה קובצי מקור
> כבדים. מה שעולה לאוויר הוא רק הגרסאות המוקטנות שהסקריפט מייצר.

---

## המבנה

```
תמונות-האתר/
└── פרויקטים/
    └── graytzer — גן גג לפנטהאוז/
        ├── הירו/      תמונה אחת — התמונה הגדולה בראש עמוד הפרויקט
        ├── שער/       אופציונלי — הכרטיס בארכיון הפרויקטים
        ├── גלריה/     כל התמונות שיופיעו בתחתית עמוד הפרויקט
        ├── לפני-אחרי/ אופציונלי — זוג תמונות להשוואה
        └── ארכיון/    מה שהוצאת מהאתר. נשמר, לא עולה לאוויר
```

**שם התיקייה:** `<מזהה באנגלית> — <שם בעברית>`. את המזהה באנגלית לא
משנים — הוא הכתובת של העמוד באתר. את השם בעברית אפשר לשנות בחופשיות.

**פרויקט חדש:** יוצרים תיקייה באותו מבנה. המזהה באנגלית באותיות קטנות
ומקפים בלבד (`beit-hadar`, לא `בית הדר` ולא `Beit Hadar`).

---

## ארבע ההחלטות שאתה עושה פה

**1. איזו תמונה תהיה ההירו** — גוררים אותה לתיקיית `הירו/`. תמונה אחת.
אם אין תיקיית `שער/`, גם כרטיס הפרויקט בארכיון ייגזר ממנה.

**2. אילו תמונות בגלריה ובאיזה סדר** — גוררים לתיקיית `גלריה/`.
הסדר נקבע לפי המספר בתחילת שם הקובץ.

**3. לפני/אחרי** — אופציונלי. שני קבצים בתיקיית `לפני-אחרי/`, אחד ששמו
מתחיל ב-`לפני` ואחד ב-`אחרי`. שניהם ייחתכו לאותו יחס בדיוק, כי הם
מוצגים זה לצד זה.

**4. מה יוצא מהאתר** — גוררים לתיקיית `ארכיון/`. בהרצה הבאה הן ייעלמו
מהאתר, והקובץ יישאר אצלך. **לא למחוק ידנית מ-`images/projects/`** —
הסקריפט מסנכרן, ומה שנמחק ידנית פשוט יחזור.

---

## שם הקובץ = הכיתוב באתר

שם הקובץ הופך לכיתוב החלופי (`alt`) של התמונה. גוגל קורא אותו, וגם
קוראי מסך של אנשים עם לקות ראייה. זה לא נראה על המסך.

```
03 פינת ישיבה עם עץ זית וקו הרקיע.jpg
▲  ▲
│  └── הכיתוב שנכנס לאתר
└───── הסדר בגלריה
```

מה שכדאי לכתוב: מה רואים בפועל — `פינת ישיבה עם עץ זית מול קו הרקיע`.
מה שלא עוזר: `IMG_4821` או `תמונה יפה`.

קובץ בלי טקסט יעבוד, אבל הסקריפט ידווח עליו כחסר-כיתוב.

---

## מיקוד החיתוך בהירו

ההירו נחתך למלבן רחב, ולכן חלק מגובה הצילום יורד. ברירת המחדל היא
לשמור את **מרכז** התמונה. אם הנושא נמצא למעלה או למטה — מוסיפים תגית
לשם הקובץ:

```
01 מבט על הגג מול קו הרקיע #למעלה.jpg
```

`#למעלה` · `#למטה` · `#מרכז` (ברירת המחדל). התגית יורדת מהכיתוב.

## איך מריצים

בדיקה — מראה מה ייווצר בלי לגעת בכלום:

```bash
cd ~/Desktop/קלוד/"אתר קלוד" && python3 build_site_images.py
```

הרצה בפועל, ואז בניית העמודים:

```bash
cd ~/Desktop/קלוד/"אתר קלוד" && python3 build_site_images.py --write && python3 build_projects.py && python3 build_assets.py --write
```

פרויקט אחד בלבד:

```bash
cd ~/Desktop/קלוד/"אתר קלוד" && python3 build_site_images.py --write --only graytzer
```

⚠️ **הסדר חשוב.** `build_projects.py` כותב את עמודי הפרויקטים מחדש
ומחזיר אותם לשלושה גיליונות CSS נפרדים; `build_assets.py --write`
מחזיר אותם לחבילה המאוחדת. דילוג על השלב האחרון מאט את האתר.

## מה הסקריפט מייצר מכל תמונה

| הקובץ באתר            | מידות                       | מקור                         |
| --------------------- | --------------------------- | ---------------------------- |
| `hero.webp`           | 1600×695                    | `הירו/` — חיתוך רחב לדסקטופ  |
| `hero-mobile.webp`    | 820×1180                    | `הירו/` — חיתוך לאורך לטלפון |
| `thumb.webp`          | 900×1200                    | `שער/`, ואם ריקה — `הירו/`   |
| `g1.webp` … `gN.webp` | רוחב 1200, היחס המקורי נשמר | `גלריה/`                     |
| `before.webp` + `after.webp` | 900×1200 שניהם | `לפני-אחרי/`      |

הפורמט הוא WebP, והדחיסה נקבעת **לפי תקציב משקל** ולא לפי דרגת איכות
קבועה: הסקריפט מוריד איכות עד שהקובץ נכנס לתקציב. הסיבה — אותה דרגת
איכות מייצרת 200KB מצילום נקי ו-690KB מקיר עלווה צפוף, וצילומי הגינות
הם בדיוק עלווה. התקציבים: הירו 190KB · הירו למובייל 150KB · שער 110KB ·
תמונת גלריה 260KB. הדוח מציג לכל קובץ את המשקל ואת האיכות שנבחרה.

**התמונות בגלריה לא נחתכות.** היחס שצילמת הוא היחס שיוצג. אם תמונה
צרה במיוחד (מעבר ל-1:2) הסקריפט יתריע, כי היא מותחת את הטור שלה.

## מה איכות המקור שכדאי לגרור לפה

הכי טוב: הקובץ המקורי מהמצלמה או מהאייפון, בלי הקטנה ובלי שליחה
בוואטסאפ (וואטסאפ מקטין ל-כ-1 מגה-פיקסל וזה נראה באתר).

מינימום מעשי: 1600 פיקסל בצד הארוך. הסקריפט לא יעצור על פחות מזה,
אבל התמונה תיראה רכה.

פורמטים: JPEG, PNG, WebP, TIFF. גם HEIC מהאייפון עובד.
