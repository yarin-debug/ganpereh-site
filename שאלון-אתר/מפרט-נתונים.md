עקרונות:
- `message` — תקציר קריא לאדם. **רשת ביטחון**: גם אם characterization לא נקלט (גרסת שרת ישנה), הליד קריא. מאפשר פריסת אתר לפני דשבורד.
- `characterization.quiz` — ‏namespace שמכיל את כל מה שלא נכנס לשדות הסטנדרטיים. מאומת ששורד עריכות בדשבורד.
- כל רשומת media **חייבת** ‏`desc` לא-ריק ‏(פילטר השמירה בדשבורד מוחק רשומות בלעדיו).
- `company` ריק = honeypot ‏(מילוי → דחייה שקטה בשרת, קיים כבר היום).
- ריטריי על כשל רשת: עד 3 נסיונות עם אותו `externalId` — ה-dedup בשרת מונע כפילויות.
- מסלולים C/D: בלי `quiz.band`; ‏`estimatedValue` לפי base+perSqm בלבד.

## 2. שינויי דשבורד (שלב 2) — ברמת קובץ

### 2.1 `src/lib/inbound-characterization.ts` — חדש

Sanitizer טהור, ‏unit-testable:

- **Allowlist שדות** — רק מפתחות `LeadCharacterization` מוכרים + ‏`quiz`. מפתח זר → מושמט.
- **Clamp מחרוזות** — שדות רגילים ≤200 תווים; ‏`existingState`/`requested`/`notWanted`/`zones` ≤2,000.
- **Enums** — ‏`sunExposure` ∈ ‏{full,partial,shade}; ‏`wind` ∈ ‏{na,mild,strong}; ‏`style` ∈ ‏{natural_wild,minimal,mediterranean,other}; ‏`irrigationExisting` ∈ ‏{none,exists}. ערך לא חוקי → מושמט.
- **scope** — רק מפתחות שקיימים ב-`work-catalog.ts` ‏(להשתמש בפונקציה/רשימה הקיימת); ‏qty/note clamped ל-200.
- **media** — עד 12 רשומות; ‏`url` חייב להיות ‏https וב-host של פרויקט ה-Supabase ‏(מ-env) — אחרת מושמט; ‏`desc` חובה.
- **quiz** — אובייקט חופשי אך: עומק ≤4, ‏`designer.elements` ≤ ‏60, סה"כ JSONB אחרי סניטציה ≤ ‏32KB ‏(מעל — לחתוך את `quiz.answers` תחילה, ואז את `designer`).
- גוף בקשה כולל > ‏100KB → דחייה ‏413 מוקדם ב-route.

### 2.2 `src/app/api/leads/inbound/route.ts` — עריכה

- קריאת `body.characterization` → העברה ב-sanitizer → הוספה לרשומת ה-insert.
- אין שדה → התנהגות זהה להיום ‏(תאימות מלאה ל-Make/Meta).
- העשרת מייל ההתראה כש-`characterization.quiz` קיים: מסלול, רמת השקעה, מס' תמונות, האם יש תרשים דיזיינר.

### 2.3 `src/app/api/leads/upload-url/route.ts` — חדש

- ציבורי, אותה תבנית CORS ‏(allowlist ‏ganpereh.co.il) + ‏OPTIONS, אותו מנגנון rate-limit — ‏**30 העלאות/שעה/IP**.
- קלט: ‏`{ fileName, contentType, sizeBytes }`. ולידציה: ‏contentType ∈ ‏{image/jpeg, image/png, image/webp, application/pdf}, ‏sizeBytes ≤ ‏10MB.
- פעולה: ‏service-role → ‏`supabase.storage.from("lead-media").createSignedUploadUrl("quiz/YYYY-MM/<uuid>.<ext>")`.
- פלט: ‏`{ signedUrl, token, path, publicUrl }`. הדפדפן מבצע ‏PUT ישירות ל-Storage ‏(עוקף את מגבלת ‏4.5MB של Vercel; ‏Storage API פתוח ל-CORS).

### 2.4 Bucket ‏`lead-media` — הקמה ידנית/SQL

כמו `quote-images`: ‏public read, כתיבה רק דרך signed URLs ‏(אין anon write). נתיבים בלתי-ניתנים לניחוש ‏(uuid). לתעד את ההקמה בקובץ ‏`supabase/lead-media.sql` או הוראה ידנית ב-README של הדשבורד — ואת ה-SQL להדביק בצ'אט לירין ‏(נוהל קבוע).

### 2.5 `src/lib/domain/characterization.ts` — עריכה

- ‏`MediaRef` מקבל ‏`url?: string`.
- ‏`LeadCharacterization` מקבל ‏`quiz?: Record<string, unknown>` ‏(מכוון להיות רופף — הדשבורד לא מפרש אותו, רק משמר).

### 2.6 `src/components/LeadCharacterization.tsx` — עריכה מינימלית

באינדקס המדיה ‏(תצוגה + שורות עריכה): כשיש ‏`m.url` — תמונה מוצגת כ-thumbnail לחיץ ‏(נפתח בטאב חדש), ‏PDF כקישור "פתח PDF". תרשים הדיזיינר מופיע כך אוטומטית בכרטיס הליד.

### 2.7 בדיקות (vitest)

- sanitizer: שדה זר מושמט · enum לא חוקי מושמט · scope עם מפתח מומצא מסונן · media בלי desc מסונן · url זר מסונן · חיתוך 32KB · payload ישן ‏(בלי characterization) עובר ללא שינוי.

## 3. צד הלקוח — העלאות (upload-client.js, שלב 4)

1. **דחיסה:** כל תמונה עוברת דרך canvas — ‏resize לצלע ארוכה ≤1,600px, ‏JPEG ‏q0.8. פותר גם HEIC מ-iPhone ‏(הדפדפן מפענח, canvas מקודד JPEG). אם הפענוח נכשל וה-MIME מותר — מעלים את המקור; אחרת שגיאה ידידותית ‏("הפורמט לא נתמך — נסו תמונה אחרת").
2. **PDF:** כמו שהוא, ≤10MB.
3. **תהליך:** בחירת קבצים → מיד ‏POST ל-upload-url → ‏PUT ברקע ‏(המשתמש ממשיך לענות) → ‏thumbnails עם מצב התקדמות במסך ההעלאה.
4. **Submit:** ממתין להעלאות תלויות ‏(ספינר "מעלים את התמונות…"), אבל **כשל העלאה לא חוסם ליד** — שולחים בלי המדיה, מיידעים בעדינות ‏("חלק מהתמונות לא עלו — אפשר לשלוח לנו בוואטסאפ").
5. ריטריי ‏PUT: עד 2 נסיונות לקובץ.
6. אירועים: ‏`quiz_upload {count, has_pdf}` בהשלמה, ‏`quiz_error {stage:"upload", code}` בכשל.

## 4. אבטחה — סיכום

| שכבה | מנגנון |
|---|---|
| מקור | CORS allowlist ‏(ganpereh.co.il בלבד) בשני ה-endpoints |
| ספאם | honeypot ‏`company` + ‏rate-limit ‏(20 לידים/דקה, 30 העלאות/שעה) |
| כפילויות | dedup לפי ‏`externalId` ‏(quiz-uuid) |
| קלט | sanitizer allowlist + ‏clamps + ‏413 מעל 100KB |
| קבצים | ‏MIME allowlist, ≤10MB, נתיבי uuid, כתיבה רק ב-signed URL |
| פרטיות | bucket ציבורי בנתיב בלתי-ניתן לניחוש ‏(תקדים quote-images); סעיף ב-privacy.html בשלב 8 |

## 5. בדיקת E2E לשלב 2 (curl)

1. ‏POST ל-inbound עם ה-payload מ-§1 ‏(עם ‏Origin: ‏https://ganpereh.co.il) → ‏200, ליד בדשבורד, האפיון גלוי, המייל התקבל.
2. ‏POST ל-upload-url עם ‏`{fileName:"test.jpg", contentType:"image/jpeg", sizeBytes:150000}` → ‏PUT קובץ אמיתי → ‏publicUrl נפתח בדפדפן.
3. ‏POST ‏payload בפורמט הישן ‏(שדות ליד בלבד) → זהה להתנהגות היום.
4. למחוק את לידי הבדיקה מהדשבורד בסיום.
