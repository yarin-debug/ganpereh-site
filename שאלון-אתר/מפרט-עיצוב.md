# מפרט-עיצוב — UI, אנימציה, נגישות, טון ואנליטיקס

*משמש את כל שלבי האתר (1, 3–7). היעד: פרימיום שקט — האסתטיקה של האתר, החוויה של אפליקציה.*

## 1. טוקנים (עותק :root ב-quiz.css — עצמאי, לא תלוי ב-CSS של האתר)

```css
:root {
  --green-dark: #1B3024;  --green-mid: #253D2C;  --green-accent: #C4623A;
  --green-pale: #FAF0EB;  --cream: #F9F9F7;      --cream-dark: #F0F0EC;
  --white: #FFFFFF;       --text: #1A1A1A;       --text-mid: #444;  --text-light: #5c5c5c;
  --radius: 16px;         --radius-lg: 24px;
  --shadow-sm: 0 2px 12px rgba(0,0,0,.06);  --shadow: 0 4px 24px rgba(0,0,0,.08);
  --shadow-md: 0 8px 36px rgba(0,0,0,.12);
}
```

פונטים: ‏Alef ‏(גוף, 400/700) + ‏TelAviv Brutalist ‏(כותרות) — ‏`@font-face` מ-`../fonts/`, ‏preload ל-woff2 ב-head, ‏`font-display: swap`. ‏`dir="rtl"` על ה-html.

## 2. שלד המסך

- מכולה מרכזית ‏max-width ‏680px, ריווח צד ‏20px במובייל.
- **Progress bar:** פס דק ‏(3px) צמוד לראש, מילוי ‏`--green-accent`, מעבר ‏`cubic-bezier(.22,.61,.36,1) .5s`. מוסתר ב-S0, בשער הפרטים ובתוצאה.
- **חץ חזרה:** למעלה בצד ימין ‏(RTL), תמיד זמין מלבד S0. לא מוחק תשובות — חוזר עם הבחירה מסומנת.
- **מבנה שאלה:** כותרת ‏(TelAviv, ‏clamp ‏1.4–1.9rem) → תת-כותרת ‏(Alef, ‏--text-mid) → אופציות → ‏skip ‏(אם יש) כקישור טקסט שקט מתחת — **לעולם לא כפתור אפור שמתחרה בתשובות**.
- גובה: ‏`min-height: 100dvh` עם המכולה ממורכזת; בשער הפרטים — ‏scroll-safe כשמקלדת פתוחה.

## 3. קומפוננטות לפי סוג מסך

| type | מראה והתנהגות |
|---|---|
| choice | גריד כרטיסים ‏(2 עמודות; 1 בצר מ-540px או כשיש תת-טקסט ארוך). כרטיס: תמונה/אימוג'י + תווית + sub. בחירה: מסגרת ‏accent + רקע ‏pale + ✓. ‏auto-advance ‏320ms |
| chips | צ'יפים מתגלגלים, בחירה מרובה, מונה עדין כשיש max ‏("עד 2"). כפתור "המשך" נדלק משבחרו ≥1 ‏(opacity ‏.45→1) |
| stepper | ‏presets כצ'יפים + שורת ‏− ‏[ערך] ‏+ ‏(מטרות מגע ‏48px), יחידה מוצגת ‏(מ״ר / קומה) |
| text | ‏textarea/input עם focus ‏ring ‏accent, ‏font-size ‏16px+ ‏(מונע זום iOS) |
| upload | אזור drop/כפתור "בחרו תמונות", גריד thumbnails עם טבעת התקדמות, X להסרה |
| contact | שדות מוערמים, ולידציה inline ‏(שגיאה מתחת לשדה, לא alert), מיקרו-אמון מתחת לכפתור |
| info | כותרת גדולה + פסקה + CTA ראשי + קישור משני |
| result | ‏§8 במפרט-מסלולים; ‏sticky CTA במובייל ‏(IntersectionObserver על הכותרת) |

## 4. אנימציה (רגעי ה"וואו" — מדודים, לא קרקסיים)

| רגע | אנימציה | משך |
|---|---|---|
| מעבר שאלה | ‏slideIn: ‏translateY ‏18px→0 + ‏opacity | ‏380ms ‏cubic-bezier(.22,.61,.36,1) |
| בחירת כרטיס | ‏scale ‏.98→1 + ✓ ‏fade | ‏150ms |
| כניסת דיזיינר | ‏line-draw של הצורה | ‏400ms |
| הוספת אלמנט | ‏pop ‏scale ‏.6→1 | ‏180ms |
| מסך תוצאה | ‏reveal מדורג של הבלוקים | ‏80ms ביניהם |
| רמת השקעה | ‏count-up עדין של הטווח | ‏600ms |

`@media (prefers-reduced-motion: reduce)` — הכול כבוי, מעברים מיידיים.

## 5. נגישות

- כל אופציה = ‏`<button>` אמיתי; ניווט מקלדת מלא ‏(Tab/Enter/רווח).
- מעבר מסך: פוקוס עובר לכותרת החדשה; ‏`aria-live="polite"` על מכולת המסך.
- בחירה לא מסומנת בצבע בלבד — תמיד גם ✓/מסגרת עבה ‏(עיוורון צבעים).
- ניגודיות ≥ ‏4.5:1 לכל טקסט ‏(לבדוק את ‏--text-light על ‏--cream).
- הדיזיינר: החלופה המלאה היא שאלות ה-fallback — מוצהרת בקישור גלוי, לא נסתרת.
- ‏axe-core נקי במסכי הליבה ‏(שלב 7).

## 6. טון ומיקרו-קופי (מחייב)

- **אסור:** "מדהים", "מטורף", "וואו", "הכי", "!!", לחץ מלאכותי, טיימרים.
- **מותר ורצוי:** חום שקט, ביטחון, הומור עדין ‏("עצים ואדניות צריכים לעלות איכשהו 🙂").
- פנייה: רבים ‏("בחרו", "ספרו לנו") — עקבי בכל השאלון.
- כל מסך ≤2 שורות טקסט מלבד info/result.
- שקיפות תמיד: "הערכה ראשונית", "המחיר נקבע בהצעה האישית בלבד" — לא מבטיחים מה שלא נקיים.
- הקופי הסופי נמצא במפרט-מסלולים — לא לאלתר ניסוחים חדשים בזמן ביצוע.

## 8. ביצועים

- ‏JS מפוצל למודולים אך בלי bundler — ‏ES modules טבעיים; סה"כ ‏JS ליבה ‏(בלי Konva) יעד < ‏60KB.
- ‏Konva נטען עצלה רק במסכי קנבס.
- תמונות אופציות: ‏webp קיימות, ‏`loading="lazy"`.
- יעד ‏Lighthouse mobile: ‏Performance ≥ ‏90, ‏A11y ≥ ‏95.
