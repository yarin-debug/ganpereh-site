# מפרט-מסלולים — כל השאלות, המיפוי וה-branching

*משמש את שלבים 1, 3, 7. הטקסט כאן הוא הקופי הסופי — לא לנסח מחדש בזמן ביצוע.*

---

## 1. סכמת שאלה (flows.js)

השאלון כולו הוא data: ‏`FLOWS = { balcony, garden, business, building }`, כל מסלול = מערך של אובייקטי שאלה. המסכים ב-`screens/` הם רנדררים גנריים לפי `type`.

```js
{
  id: "A_sun",                    // מזהה יציב — משמש גם באנליטיקס וגם ב-answers
  type: "single",                 // single | chips | stepper | text | city | composite |
                                  // upload | photopins | designer | contact | info | result
  title: "כמה שמש מקבל החלל?",
  subtitle: "אפשר להעריך — נדייק בביקור",   // אופציונלי
  options: [                      // ל-single/chips
    { value: "full", label: "שמש מלאה רוב היום", sub: "6+ שעות", icon: "☀️", img: null }
  ],
  max: 2,                         // ל-chips: מקסימום בחירות (ברירת מחדל: בלי הגבלה)
  map: {                          // מיפוי לשדות — ראה מפרט-נתונים
    path: "characterization.sunExposure",
    values: { full: "full", partial: "partial", shade: "shade", unsure: null }
  },
  skippable: false,               // true → קישור "דילוג" שקט מתחת לאופציות
  skipLabel: "לא בטוח/ה — דלגו",   // טקסט הדילוג אם שונה מברירת המחדל
  showIf: (state) => true,        // branching — פונקציה על ה-state
  autoAdvance: true               // single: התקדמות אוטומטית 320ms אחרי בחירה
}
```

כללי מנוע: שאלה אחת למסך · חץ חזרה תמיד (מימין למעלה, RTL) · progress = אחוז השאלות שנענו במסלול (מסכי info/result לא נספרים) · כל מעבר יורה `quiz_step`.

## 2. פתיחה משותפת

### S0 — פתיחה (info)

- **כותרת:** בואו נאפיין את החלל שלכם
- **תת-כותרת:** כ-4 דקות, שאלה אחת בכל פעם. בסוף — פרופיל פרויקט, רמת השקעה משוערת, והצעה אישית תוך 24–48 שעות.
- **מיקרו-אמון:** ללא התחייבות · הפרטים נשארים אצלנו בלבד
- **CTA:** מתחילים
- אירוע: `quiz_start {quiz_version: 2}`

### S1 — סוג הנכס (single, כרטיסים עם תמונות)

**"איזה חלל אנחנו הופכים לפרא?"**

| אופציה | תת-טקסט | flow | property_type |
|---|---|---|---|
| מרפסת | גם קטנה — זה המגרש הביתי שלנו | balcony | `balcony` |
| גג / גינת גג | שטח פתוח עם פוטנציאל גדול | balcony | `roof_garden` |
| פנטהאוז | מרפסות גדולות, סטנדרט גבוה | balcony | `penthouse` |
| גינה פרטית / וילה | קרקע, אדמה, שורשים | garden | ‏(מדויק ב-B1) |
| עסק או משרד | ירוק שעובד בשבילכם | business | ‏(מדויק ב-C1) |
| שטח משותף בבניין | לובי, חצר, גג משותף | building | `other` |

Deep-link: ‏`/quiz/?type=balcony|roof|penthouse|garden|business|building` מדלג על S1 עם ערך מוגדר (שלב 8).
אירוע: `quiz_flow_selected {flow}`.

## 7. שער פרטים (contact — כל המסלולים)

- **כותרת:** הפרופיל שלכם מוכן — לאן לשלוח את ההצעה האישית?
- **שדות:** שם מלא ‏(חובה) · טלפון ‏(חובה, ולידציה: ‏`^0(5\d|[23489])\d{7}$` אחרי ניקוי מקפים/רווחים; קידומת ‎+972 מנורמלת ל-0) · אימייל ‏(רשות, ולידציית פורמט בסיסית)
- **Honeypot:** שדה `company` נסתר ‏(CSS, לא ‏`display:none` בלבד — גם ‏`position:absolute; right:-9999px`, ‏`tabindex="-1"`, ‏`autocomplete="off"`)
- **מיקרו-אמון:** ההצעה מגיעה בוואטסאפ או בשיחה — בלי ספאם ובלי רשימות תפוצה.
- **כפתור:** שלחו לי את ההצעה ←
- בזמן שליחה: הכפתור הופך ל"מכינים את הפרופיל…" ‏(≈1.2 שניות בזמן שהבקשה באוויר — אמיתי, לא מזויף). כשל: הודעה עדינה + כפתור נסיון חוזר ‏(אותו externalId — בטוח לכפילויות) + קישור וואטסאפ כ-fallback.
- אירועים: `quiz_contact_view` בכניסה, `quiz_submit` בהצלחה ‏(+ ‏`gpTrackLead("quiz")` → ‏Lead בפיקסל).

## 8. מסך תוצאה (A + B)

סדר בנייה ‏(reveal מדורג ‏80ms):

1. **"הפרופיל של הפרויקט שלכם"** — snapshot מהדיזיינר או התמונה הראשונה שהועלתה ‏(אם אין — תמונת הסגנון שנבחר) + chips של תשובות מפתח: סוג · גודל · סגנון · עדיפויות · לו"ז.
2. **רמת השקעה משוערת** — שם הרמה + הטווח + שורה: "הערכה ראשונית לפי מה שסיפרתם — המחיר נקבע בהצעה האישית בלבד."
