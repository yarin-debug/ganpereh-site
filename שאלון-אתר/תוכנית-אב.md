# תוכנית-אב — שאלון אפיון גן פרא

*אושרה ע"י ירין: 6.7.2026 · מסמך זה הוא מקור האמת לחזון, להחלטות ולסטטוס השלבים.*

---

## 1. החזון

להחליף את שאלון המחיר הישן (`אתר קלוד/quiz.html`) בכלי אפיון פרימיום שהוא גם נכס שיווקי וגם כלי עבודה:

- **ללקוח:** חוויה זורמת, שאלה אחת בכל פעם, ממשק מתוחכם ומהנה (דיזיינר מרפסת "כמו משחק"), העלאת תמונות, ובסוף — פרופיל פרויקט + רמת השקעה + הבטחת הצעה אישית תוך 24–48 שעות.
- **לירין:** כל תשובה ממופה לשדה בסכמת האפיון של הדשבורד. ליד שמגיע מהשאלון מגיע עם אפיון כמעט מלא — אפשר להוציא ממנו תוכנית, כתב כמויות והצעת מחיר במינימום שאלות המשך.

### מה שומרים מהשאלון הישן

Auto-advance ‏(320ms), progress bar עליון, כרטיסי בחירה עם תמונות, ניקוד לידים, מיקרו-אמון, sticky CTA במובייל, RTL מלא, אנימציות slideIn, אירועי GA4/פיקסל.

### מה הורגים

טווח מחיר מנופח ~30%, מסך "טעינה" מזויף, value stack ובונוסים, שליחה ל-Formspree (מוחלף בזרימה לדשבורד).

## 2. החלטות נעולות (אין לפתוח מחדש)

1. **בנייה באתר הסטטי** — `אתר קלוד/quiz/`, vanilla JS ‏(ES modules, בלי build), Konva.js מ-CDN. הדשבורד מקבל הרחבת API קטנה בלבד.
2. **מסך סיום** — רמת השקעה (4 רמות בשמות, טווחים רחבים) + הצעה אישית תוך 24–48 שעות. בלי מחיר מדויק.
3. **דיזיינר מלא רק למרפסת/גג/פנטהאוז.** גינה: מסלול עשיר + תמונות + פינים על תמונה. עסק/בניין: מסלולים רזים → שיחה.
4. **ביצוע ב-8 שלבים** ע"י מודל חסכוני, לפי הפרוטוקול ב-`CLAUDE.md` של תיקייה זו.

## 3. עובדות מאומתות בקוד (6.7.2026)

- `POST /api/leads/inbound`: ‏CORS ל-ganpereh.co.il בלבד, honeypot ‏(`company`/`_gotcha`), rate-limit ‏20/דקה/IP, dedup לפי `external_id`, ‏fallback ל-`failed_leads`. **מתעלם כיום מ-`characterization`** — שלב 2 מתקן.
- `leads.characterization` JSONB קיים; עריכה בדשבורד שומרת עם spread — מפתחות זרים (namespace ‏`quiz`) שורדים. רשומת media בלי `desc` נמחקת בפילטר השמירה — תמיד לשלוח `desc`.
- מפתחות קטלוג (מ-`work-catalog.ts`): ליבה `pots, substrate, planting, irrigation, lighting, transport` · נוסף `trees, soil, demolition, lawn, paving, pergola, deck, shading, water, furniture, pruning, maintenance, other`.
- `lead-score.ts` valueConfig ‏(₪, לפני מע"מ): balcony ‏8,000+900/מ״ר ‏[12–80K] · roof_garden ‏12,000+1,100 ‏[20–160K] · ground_garden ‏10,000+700 ‏[15–220K] · penthouse ‏15,000+1,200 ‏[30–220K] · villa ‏20,000+800 ‏[35–320K] · office/business ‏10,000+700 ‏[12–130K] · other ‏10,000+800 ‏[12–150K].
- מגבלת גוף בקשה ב-Vercel ‏4.5MB → העלאות ישירות ל-Supabase Storage ‏(signed URLs). תקדים bucket ציבורי: `quote-images`.
- טוקנים: `--green-dark #1B3024 · --green-mid #253D2C · --green-accent #C4623A · --green-pale #FAF0EB · --cream #F9F9F7 · --cream-dark #F0F0EC · radius 16/24`. פונטים: Alef ‏(גוף), TelAviv Brutalist ‏(כותרות) — `אתר קלוד/fonts/`. ‏GA4 ‏`G-2EYWMVWQ26`, פיקסל `1300499277768920`.
- השאלון הישן לא מקושר משום עמוד (orphan) — אין סיכון בהחלפה הדרגתית.

## 4. ארכיטקטורה

```
אתר קלוד/quiz/
├── index.html              # shell: head, preload פונטים, GA4+פיקסל, מכולות #screen #progress #sticky-cta
├── css/quiz.css            # טוקנים (עותק :root), פריסות כל סוגי המסכים, אנימציות
├── css/designer.css        # קנבס, bottom-sheet פלטה, פס פעולות
└── js/
    ├── config.js           # INBOUND_URL, UPLOAD_URL, DRY_RUN, מגבלות, מספר וואטסאפ
    ├── analytics.js        # trackEvent(name, props) → gtag + fbq trackCustom + dataLayer
    ├── state.js            # אובייקט state יחיד; sessionStorage (resume); externalId="quiz-"+uuid
    ├── flows.js            # ⭐ כל השאלות כ-data (סכמה במפרט-מסלולים §1)
    ├── engine.js           # רנדר, קדימה/אחורה, showIf, progress, מעברים, פוקוס, אנליטיקס
    ├── screens/            # base, choice, chips, stepper, textinput, upload, photopins,
    │                       # designer, contact, info, result — רנדררים לפי type
    ├── designer/           # index, stage, shape, palette, elements, controls, serialize, snapshot
    ├── upload-client.js    # דחיסה ל-JPEG≤1600px q0.8, PUT ל-signed URL, ריטריי, רקע
    ├── band.js             # מנוע רמות השקעה — כל המספרים בקונפיג אחד
    └── submit.js           # בניית payload, POST, ריטריי עם אותו externalId, fallback UI
```

`quiz.html` הישן → בשלב 8 מוחלף ב-stub הפניה ‏(meta refresh + `location.replace('/quiz/')` + קישור נראה).
