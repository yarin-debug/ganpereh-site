# מפרט-דיזיינר — לוח המרפסת האינטראקטיבי

*משמש את שלבים 5–6. החלק הכבד של הפרויקט — מפורק לתתי-שלבים D1–D5.*

---

## 1. עקרונות

- **מובייל קודם.** רוב המשתמשים בטלפון. כל אינטראקציה חייבת לעבוד באצבע.
- **פשוט ומקסים, לא CAD.** דיוק של חצי מטר מספיק לאפיון. אין zoom/pan ב-v1 — הצורה תמיד fit-to-screen. זה מוריד מחלקה שלמה של באגי מגע.
- **אפס נכסי תמונה.** כל אלמנט = ‏`Konva.Group` של מלבן מעוגל + אימוג'י ‏(Text) + תווית ‏(Text, ‏Alef). ‏(`document.fonts.ready` לפני ציור ראשון.)
- **ה-fallback הוא מסלול מדרגה ראשונה** — גם נגישות (מקלדת/קורא מסך) וגם ביטוח לכשל CDN.

## 2. טעינה

Konva ‏v9 מ-CDN ‏(`https://unpkg.com/konva@9/konva.min.js`), מוזרק דינמית רק כשמגיעים למסך הדיזיינר ‏(או photopins). ‏timeout ‏8 שניות → אם לא נטען: אירוע `quiz_designer_fallback {reason:"load"}` ומעבר שקוף לשאלות A_fallback_size/existing/wants. בנוסף, מתחת לקנבס תמיד קיים קישור שקט: **"מעדיפים רשימה במקום מפה?"** → אותו fallback, מרצון ‏(`{reason:"choice"}`). מעבר בין המצבים לא מאבד נתונים שכבר הוזנו.

## 3. D1 — במה, צורה ומידות

- **Stage:** רוחב המכולה ‏(מקס' 680px), גובה ‏≈56vh. שכבות: גריד ‏(סטטי) · צורה · אלמנטים · UI.
- **בחירת צורה:** שני כרטיסים — **מלבן** / **צורת ר** ‏(L). צורות חופשיות נחתכו במכוון; מיקרו-קופי: "צורה מיוחדת? צרפו תמונה בשלב הבא ונבין הכול."
- **מידות:** steppers בצעדי ‏0.5 מ׳ — רוחב ‏1–25 מ׳, עומק ‏1–15 מ׳. צורת ר מוסיפה: פינה חתוכה ‏(בחירת פינה מ-4) + רוחב/עומק החיתוך. המידות מוצגות כתוויות על קצוות הצורה ‏("4.5 מ׳").
- **קנה מידה:** ‏`pxPerM = stageWidth × 0.86 / widthM` — הצורה תמיד ממלאת ‏86% מרוחב הבמה.
- **גריד:** קווים כל ‏0.5 מ׳, ‏`--cream-dark`, דק. בתוך הצורה בלבד.
- **חישוב שטח:** מלבן ‏`w×d`; צורת ר ‏`w×d − cutW×cutD`. מעוגל למ״ר שלם → ‏`sizeSqm`.
- **אנימציית כניסה:** הצורה נמתחת לקווים ‏(line-draw ‏400ms) — רגע ה"וואו" הראשון.

## 5. D3 — בחירה, פס פעולות, undo

- **בחירה:** טאפ על אלמנט → מסגרת הדגשה ‏(`--green-accent`) + **פס פעולות צף** מעל הקנבס ‏(לא ידיות Transformer זעירות — החלטת מובייל): ‏🔄 סובב ‏45° · ‏− / ‏+ גודל ‏(צעדי ‏0.25 מ׳, מינימום ‏0.3, מקסימום גודל הצורה) · ‏⧉ שכפל ‏(היסט ‏0.5 מ׳) · ‏🗑 מחק · ↔ החלף קיים/רצוי.
- **ביטול בחירה:** טאפ על רקע.
- **Undo:** מחסנית snapshots של ה-state הלוגי ‏(לא ה-Konva) — עד ‏20 צעדים. כפתור ↩ קבוע בפינת הקנבס.
- **ריק:** כשאין אלמנטים — רמז רפאים במרכז: "גררו לכאן את החלומות 🌿".

## 6. D4 — מצבי קיים/רצוי, סריאליזציה, snapshot

**שני מצבים ויזואליים:**
- `existing` ‏(מה קיים): מתאר אפור ‏(`--text-light`), מילוי שקוף.
- `desired` ‏(מה חולמים): מילוי ירוק-טרקוטה רך לפי סוג ‏(צמחי → ירוק ‏`--green-pale` עם מסגרת ‏`--green-mid`; בנוי → ‏`--green-pale`/טרקוטה).

**סריאליזציה ‏(serialize.js) — מטרים, בלתי תלוי מכשיר:**

```json
{
  "version": 1,
  "shape": { "type": "rect", "widthM": 4.5, "depthM": 2.5,
             "cut": { "corner": "top-left", "widthM": 1.5, "depthM": 1.0 } },
  "elements": [
    { "id": "e1", "type": "pergola", "status": "desired",
      "xM": 0.5, "yM": 0.2, "wM": 3, "hM": 3, "rotation": 0 }
  ],
  "counts": { "desired": { "pergola": 1, "pots": 4 }, "existing": { "water_point": 1 } }
}
```

‏(`cut` רק בצורת ר. ‏`xM,yM` = פינת האלמנט ביחס לפינת הצורה.)

**גזירת נתונים מהדיזיינר:**
- `sizeSqm` ← שטח הצורה.
- `counts.desired` ← בחירת scope אוטומטית: ‏`{key, selected:true, qty:"N יח׳ · WxH מ׳", note:"מהדיזיינר"}` ‏(qty מסכם: "2 יח׳ · ‏3×3 מ׳" או ל-deck/lawn סה"כ מ״ר).
- `counts.existing` של מים/חשמל ← רמזים באפיון ‏(מים קיימת → הערה "יש נק' מים במרפסת" ב-existingState).

**Snapshot ‏(snapshot.js):** ביטול בחירה → ‏`stage.toDataURL({ pixelRatio: 2, mimeType: "image/png" })` → ‏Blob → מועלה כמו תמונה רגילה ‏(מפרט-נתונים §3) → נכנס ל-media עם ‏`desc: "תרשים החלל (מהשאלון)"`. נכשל? ממשיכים בלי — לא חוסם.

## 7. D5 — ליטוש מובייל וחיווט

- בדיקת ארגונומיה על מכשיר אמיתי: גודל מטרות מגע ‏(≥44px), פס הפעולות לא מוסתר ע"י האצבע, ה-bottom sheet לא מתנגש עם ה-progress.
- מניעת גלילת דף בזמן גרירה על הקנבס ‏(`touch-action: none` על מכולת הבמה בלבד).
- חיווט מלא במסלול A: כפתור "סיימתי ✓" → ‏serialize + snapshot + ‏`quiz_designer_done {desired_count, existing_count, duration_sec}` → המשך ל-A_sun.
- כפתור "דלגו" בתוך הדיזיינר ‏(בנוסף לזה שבמסך ההקדמה) → ‏`quiz_designer_skip` → שאלות fallback.

## 8. photopins (מסלול B — שימוש חוזר בתשתית)

מסך נפרד ‏(`screens/photopins.js`) שמשתמש באותה טעינת Konva: התמונה שהועלתה כרקע ‏fit-to-stage; טאפ מוסיף פין ממוספר ‏(עיגול טרקוטה + מספר) ופותח בורר תווית ‏(פינת ישיבה · צמחייה · דשא · פינת אוכל · משחק לילדים · אחר+טקסט); גרירת פין מותרת; טאפ על פין קיים → שינוי תווית או מחיקה. תוצרים: ‏`zones` טקסטואלי ‏("1 ישיבה · 2 דשא · 3 אחר: ג'קוזי") + ‏snapshot של התמונה עם הפינים → ‏media עם ‏`desc: "סימון אזורים (מהשאלון)"`.
